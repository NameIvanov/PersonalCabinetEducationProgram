# Создание базы данных с нуля

Для MySQL 8 выполняйте файлы строго по порядку:

1. `init.sql` — создаёт базу и актуальную структуру таблиц.
2. `migrate_to_identity.sql` — завершает настройку ASP.NET Identity и регистрирует миграции EF Core.
3. `seed.sql` — добавляет начальные данные.

Все три файла рассчитаны на последовательный запуск в базе `personal_cabinet`.
`init.sql` предназначен для новой пустой базы. `migrate_to_identity.sql` и
`seed.sql` можно запускать повторно.

Записи `file_path` из `seed.sql` содержат только ссылки на файлы. Сами документы
не входят в базу данных и должны отдельно находиться в каталоге, указанном в
`FileStorageSettings:StoragePath`.
